## 🚀 Быстрый старт

### 1️⃣ Выбери где хранить репозиторий (GitHub или свой сервер):

**Вариант A: GitHub** (проще, облако)
- Создай репозиторий на https://github.com/new
- Скопируй команду и выполни локально в папке `c:\nowgoal_bot\new_bot_playwrite`:
  ```powershell
  git remote add origin https://github.com/ТВ_ЮЗЕРНЕЙМ/nowgoal-bot.git
  git push -u origin prod
  git push -u origin dev
  ```

**Вариант B: Собственный сервер на Ubuntu** (полный контроль, автоматический перезапуск)
- Следи инструкцию в файле `GIT_WORKFLOW.md` → раздел "Вариант 2"

### 2️⃣ Повседневная работа:

```powershell
# Переключись на dev для разработки
git checkout dev

# Сделай изменения в файлах...

# Добавь и закоммитъ
git add .
git commit -m "описание изменений"

# Пушь на сервер
git push origin dev
```

### 3️⃣ На Ubuntu сервере:

```bash
# Получи обновления
git fetch origin
git pull origin dev

# Когда dev готова - мерж в prod
git merge origin/dev
git push origin prod
```
